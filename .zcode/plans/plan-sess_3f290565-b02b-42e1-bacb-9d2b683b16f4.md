## 目标
从空目录搭建一个可部署到 GitHub Pages 的个人日记前端：日常只需把 Markdown 文件提交到 `daily/`，GitHub Actions 自动构建，网站自动更新。

## 技术方案
- 使用 Astro 静态站点生成器，适合 GitHub Pages，使用 GitHub Actions 自动发布。
- 使用 TypeScript + Astro 内容集合 API 读取并校验 Markdown front matter。

## 内容约定
- 日记文件放在 `daily/` 目录，文件名采用 `YYYYMMDD.md`，例如 `20260830.md`。
- front matter 固定支持 `title`、`date`、`writer`；`writer` 默认显示 `QiuLingYan`。
- 网站按 `date` 倒序展示日记，每篇日记生成稳定的 `/daily/<slug>/` 详情页。
- 主页加入一个低调的“写作规范”提示区域，提醒：文件放置位置、文件名格式、front matter 示例、作者值和提交后自动发布流程。它使用中性边框与小字号，不喧宾夺主；详情页不重复显示。

## 视觉与交互方向
- 高级白色苹果风，不使用蓝色：白色/暖白背景、黑灰文字、银灰边框、柔和中性阴影；强调色使用黑色、石墨色或低饱和暖灰。
- 系统字体栈、宽松留白、细边框、适度圆角、轻量层次感。
- 完整暗黑模式：默认跟随 `prefers-color-scheme`，顶部提供手动切换按钮；选择保存到 `localStorage`，初始化脚本避免刷新闪烁。
- 支持移动端响应式布局、键盘焦点样式和 `prefers-reduced-motion`。

## 页面与组件
1. `src/layouts/BaseLayout.astro`：元信息、导航、站点标题、主题初始化。
2. `src/components/ThemeToggle.astro`：明暗主题切换。
3. `src/components/WritingGuide.astro`：小型写作规范提示卡，包含命名与 front matter 模板。
4. `src/pages/index.astro`：主页标题、作者信息、日记数量、写作规范和倒序日记列表。
5. `src/pages/daily/[...slug].astro`：日记详情、标题、日期、作者和 Markdown 正文。
6. `src/pages/404.astro`：简洁错误页。
7. `src/styles/global.css`：中性色设计 token、明暗主题、卡片、排版、响应式规则。
